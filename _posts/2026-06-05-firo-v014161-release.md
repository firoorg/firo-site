Firo v0.14.16.1 is a mandatory release. **All users must update to this version even if they have already updated to v0.14.16.0.** All wallets, full nodes, and masternodes must be updated prior to block 1,329,000 (approximately 22 June 2026).

As always, please **backup your wallet** before updating.

Download the latest release here: [https://github.com/firoorg/firo/releases/tag/v0.14.16.1](https://github.com/firoorg/firo/releases/tag/v0.14.16.1)

---

## What's New

### Spark Name Overflow Fix

This release resolves an overflow bug in Spark Name handling that was present in v0.14.16.0. The fix is the primary reason this follow-up release is mandatory - all users on v0.14.16.0 must update to ensure correct Spark Name behavior at and beyond the activation block.

### Minor Spark Name Vulnerability Fix

Fixes a minor vulnerability where a Spark Name transfer permission could remain valid indefinitely. Transfer permissions now expire correctly, limiting the window in which they can be used.

### Receive Request Model Fix

Fixes crashes in the receive request dialog and incorrect handling of recent request history in the Qt wallet.

### Spark Address Book Refresh Fix

Fixes a bug where Spark address book options could remain unavailable after syncing past the Spark activation block, requiring a wallet restart to resolve. The wallet now correctly detects activation even when the sync jumps past the exact activation height.

### Lelantus Strip

Internal cleanup work removing legacy Lelantus components as the protocol continues to consolidate around Lelantus Spark.

## Update Deadline

This is a mandatory update that supersedes v0.14.16.0. **All wallets, full nodes, and masternodes must be updated to v0.14.16.1 before block 1,329,000, approximately 22 June 2026.** This applies even if you recently updated to v0.14.16.0.
