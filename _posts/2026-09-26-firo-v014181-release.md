Firo v0.14.18.1 puts the desktop wallet front and center, with a refreshed interface, smoother interactions, and major memory savings for full nodes.

## A New Look and Smoother Experience

The [Firo Core redesign](https://github.com/firoorg/firo/pull/1914) refreshes the Overview, Send, Receive, transaction history, and masternode screens. It adds a collapsible sidebar, switchable light and dark themes, and a dedicated Spark Names page. [Responsiveness improvements](https://github.com/firoorg/firo/pull/1924) also make the interface smoother to use during everyday wallet activity.

## Major Memory Savings

Firo Core now keeps block privacy data in memory [only when it is needed](https://github.com/firoorg/firo/pull/1884). Previously, even blocks without that data reserved space for it. This reduces unnecessary memory use and gives full-node and masternode operators more headroom on their existing machines.

Back up your wallet before updating, then get v0.14.18.1 from the [official Firo releases page](https://github.com/firoorg/firo/releases).
